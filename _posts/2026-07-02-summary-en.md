## [First Synthetic Cell That Grows and Divides Created](https://www.quantamagazine.org/for-the-first-time-a-cell-built-from-scratch-grows-and-divides-20260701/) ⭐️ 10.0/10

Scientists led by Dr. Kate Adamala have created SpudCell, the first synthetic cell built from nonliving components that can grow, replicate its DNA, and divide, as reported on July 1, 2026. This breakthrough overcomes a major hurdle in synthetic biology, bringing us closer to creating truly autonomous artificial life, with potential applications in biotechnology, medicine, and fundamental biology research. SpudCell achieves division without a cytoskeleton by using a simplified mechanism; however, it still requires external nutrients and helper molecules, and is not yet fully self-sustaining.

hackernews · defrost · Jul 1, 14:20 · [Discussion](https://news.ycombinator.com/item?id=48747304)

**Background**: Synthetic biology aims to build artificial cells from scratch using nonliving materials. Prior work achieved growth and DNA replication in synthetic cells, but cell division—a complex process involving cytoskeletal reorganization—remained elusive. SpudCell bypasses this by using a different, engineered division mechanism.

## [Box3D: New Open-Source 3D Physics Engine from Box2D Creator](https://box2d.org/posts/2026/06/announcing-box3d/) ⭐️ 9.0/10

Erin Catto announced Box3D, an open-source 3D physics engine written in C, extending his widely-used Box2D library to three dimensions. Box2D has been foundational in game development and reinforcement learning environments; Box3D aims to bring similar simplicity and robustness to 3D physics, potentially impacting game engines, simulations, and ML benchmarks. Box3D is entirely implemented in C and includes a native C API, with features like a sensor system and a robust Soft Step rigid body solver. It focuses on rigid body dynamics and physical plausibility, though details on determinism for networking are not yet provided.

hackernews · makepanic · Jul 1, 12:12 · [Discussion](https://news.ycombinator.com/item?id=48745445)

**Background**: Box2D is a free and open-source 2D physics engine created by Erin Catto, used in popular games like Angry Birds and in Unity engine. It also underpins many reinforcement learning environments in OpenAI Gym. Box3D is the long-anticipated 3D counterpart, aiming to fill a gap in the open-source 3D physics engine space.
