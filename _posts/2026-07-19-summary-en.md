## [LG Monitors Install Software via Windows Update Without Consent](https://videocardz.com/newz/lg-monitors-silently-install-software-through-windows-update-without-user-consent) ⭐️ 9.0/10

LG monitors are silently installing software on Windows PCs through Windows Update without user consent, triggered simply by plugging in an LG monitor via HDMI. This poses a significant security and privacy risk as the software runs with full system access, starts on boot, and installs without user interaction, potentially affecting all LG monitor users. The software is installed automatically when a new LG monitor is connected or if an older LG monitor is already connected, and it has internet access with no sandboxing, starting with every system boot.

hackernews · baranul · Jul 18, 10:21 · [Discussion](https://news.ycombinator.com/item?id=48956688)

**Background**: Windows Update can deliver driver and manufacturer software updates, but typically requires user consent. In this case, LG is using a mechanism to push software without explicit approval, which users can disable by preventing automatic download of manufacturer apps in device installation settings.

## [Basalt Labs Exposed for Faking HLE Benchmark Score](https://www.reddit.com/r/LocalLLaMA/comments/1uztylz/basalt_labs_pulling_a_generationally_dumb_scam/) ⭐️ 8.0/10

A Reddit user exposed Basalt Labs for fraudulently claiming a 99.44% score on the Humanity's Last Exam (HLE) benchmark. The company's released model is based on Qwen2.5-7B-Instruct, while the model served on their website is actually DeepSeek. This undermines trust in AI research and benchmark reporting, as it demonstrates deliberate fraud to appear superior. It highlights the need for transparency and verification in model evaluations. The claimed score of 99.44% on HLE is extraordinarily high, and the deception involves using a different, likely stronger model (DeepSeek) for inference. The released open-source model is Qwen2.5-7B-Instruct, which is significantly smaller and less capable.

reddit · r/LocalLLaMA · /u/WithoutReason1729 · Jul 18, 11:58

**Background**: The Humanity's Last Exam (HLE) is a multi-modal benchmark designed to be extremely challenging, often used to evaluate frontier AI models. Qwen2.5-7B-Instruct is a 7-billion parameter model from Alibaba's Qwen series, while DeepSeek is a more advanced model known for strong performance. Benchmark fraud undermines the credibility of AI advances.

## [Claude Fable 5 Now Permanent in Anthropic Subscriptions](https://simonwillison.net/2026/Jul/18/claude-make-fable-5-permanent/#atom-everything) ⭐️ 7.0/10

Anthropic has reversed its plan to remove Claude Fable 5 from subscription plans, announcing that starting July 20, Fable 5 will be included in Max and Team Premium plans at 50% of limits, with a one-time $100 credit for others. This decision reflects intense competition in the AI model market, where rivals GPT-5.6 Sol and Kimi 3 pressured Anthropic to retain their best model in subscriptions. It signals that model availability is a key differentiator in subscription pricing. Fable 5 will be included at 50% of usage limits for Max ($100/month) and Team Premium plans, while Pro and Team Standard users get a one-time $100 credit. The $20/month plan still lacks Fable 5 access.

rss · Simon Willison · Jul 18, 06:00

**Background**: Claude Fable 5 is a powerful large language model from Anthropic, released on June 9, 2026, as a safer version of the Mythos-class model. Anthropic initially planned to remove Fable 5 from subscriptions due to compute constraints, making it API-only. However, competitive pressure from OpenAI's GPT-5.6 Sol (a flagship coding model) and Moonshot AI's Kimi 3 led them to reverse course.
